# Third-Party Notices

JARVIS can use the Kokoro local text-to-speech model for its default British male voice.

## Kokoro model

- Model: Kokoro-82M
- Default JARVIS voice: `bm_george`
- Model weights license: Apache License 2.0
- Model source: https://huggingface.co/hexgrad/Kokoro-82M

## kokoro-onnx

- Runtime: `kokoro-onnx`
- License: MIT
- Source: https://github.com/thewh1teagle/kokoro-onnx

The JARVIS application does not represent the `bm_george` voice as any real actor or celebrity. The voice is used as a general British male computer-assistant voice.

The Kokoro model files are downloaded on first use into the user's JARVIS profile directory rather than being stored in this repository. Applicable upstream license texts and notices should be retained when redistributing upstream model/runtime files.
